# Najprostsze zbudowanie COOL-VPN APK

1. Utwórz repozytorium na GitHubie.
2. Wgraj cały projekt z tego archiwum do repozytorium.
3. Wejdź w zakładkę **Actions**.
4. Wybierz **Build COOL-VPN APK**.
5. Kliknij **Run workflow**.
6. Po zakończeniu otwórz wykonanie workflow i w sekcji **Artifacts** pobierz **COOL-VPN-debug**.

Workflow sam instaluje JDK, Android SDK, Android 35 i NDK oraz buduje APK.
